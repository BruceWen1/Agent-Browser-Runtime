# ADR-0001 初始契约与工具链

- 状态：Accepted。
- 日期：2026-10-10。
- 对应需求：RPD-003、RPD-008、RPD-027。

工程采用 Node.js 24.15.0、TypeScript 6.0.3、Rust 1.99.0、MCP SDK 2.3.1 和 Playwright 1.64.0。TypeScript 版本满足当前 lint 依赖声明的支持范围，包版本及传递依赖通过锁文件固定。

公共工具输入使用 JSON Schema 2020-12 作为规范化边界，AJV 完成运行时校验。MCP 适配所需的 Zod 对象从同一数据定义转换，并使用固定版本和契约测试验证转换结果。Zod 的转换入口属于实验接口，因此升级时需要重跑双向接受与拒绝测试。

动作结果增加审批编号和实际文本输入策略。观察结果增加当前 URL、标签信息和坐标转换元数据。扩展字段在首次发布前统一冻结，并保持跨语言数据模型一致。

普通 Python 工具使用经用户确认的 Conda 环境；Chromium 的官方隔离 Python 工具链具有用户明确批准的独立例外。代码注释和函数说明采用英文。
